# Cherry Studio 配置指南

在 Cherry Studio 中使用 LinianAPI：

1. 打开 Cherry Studio 的「服务商 / API 设置」。
2. 添加一个 OpenAI 兼容的服务商。
3. 将 API 地址（Base URL）设置为 `https://api.linianai.com/v1`。
4. 填入你的 API Key（控制台创建的令牌）。
5. 填入模型名（见价格表）。

关键参数：

- Base URL：`https://api.linianai.com/v1`
- API Key：你的令牌
- Model：按需选择，见 [`docs/pricing-live.md`](pricing-live.md)
